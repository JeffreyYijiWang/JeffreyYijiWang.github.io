Computer Graphics and Visualization

Human Body Visualization

An interactive volumetric visualization system for exploring human anatomy through aligned image slices, oblique cross sections, skeleton extraction, and procedural visual effects.

  • Python
  • ModernGL
  • NumPy
  • Computer Graphics

Project Overview

The project converts stacks of anatomical images into a three-dimensional volume that can be explored through frontal, sagittal, transverse, and locally oblique planes.

I developed tools for volume preprocessing, skeletal structure extraction, distance-field generation, waypoint animation, and real-time GPU rendering.

Technical Features

  • GPU-accelerated volume rendering with ModernGL
  • Frontal, sagittal, and transverse slice navigation
  • Local oblique cross-section visualization
  • Skeleton and distance-field preprocessing
  • Animated camera and waypoint interpolation
  • Procedural pixel sorting and growth effects
