02 / C++ / DIRT / Light transport

Monte Carlo Refractive Caustics

A physically based ray tracer built in C++ using the DIRT rendering framework to generate complex reflective and refractive caustics. The renderer combines Monte Carlo path tracing, specular manifold sampling, Newton-based light-path solving, multiple importance sampling, BVH acceleration, and multithreading to simulate realistic light transport through mirrors, glass spheres, and layered dielectric materials.
